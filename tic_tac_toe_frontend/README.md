# Tic Tac Toe — Minimalistic React Frontend

A lightweight, two‑player Tic Tac Toe game built with React and vanilla CSS.

## Features
- Start New Game
- Player turn indication
- Centered 3×3 board rendering
- Win/draw detection with winning line highlight
- Reset current game
- Minimalistic, light theme using primary `#1976d2` and accent `#ff4081`

## Scripts
- `npm start` — run locally at http://localhost:3000
- `npm test` — run tests
- `npm run build` — production build

## Notes
- Accessible labels for squares (e.g., “Cell 1, X”)
- No external UI libraries; pure React + CSS
